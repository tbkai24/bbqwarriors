BBQWarriors Schema (bbqwarrior.sql)

          
This isolated SQL schema replaces the legacy yt_streamers model. It introduces bbq_creators, bbq_embed_links, and bbq_spotify_playlists so YouTube streams and Spotify playlists can be managed without overlapping legacy tables.

New bbqwarrior.sql Schema

            Isolated bbqwarrior.sql
          

          
Unified YouTube Streamers + Spotify Playlist schema for Josh Cullen & BBQWarriors.


          
-- Isolated Schema in schema/bbqwarrior.sql
CREATE TYPE bbq_media_type_enum AS ENUM ('yt_stream', 'spotify_playlist', 'spotify_track');

CREATE TABLE bbq_creators (
    creator_id VARCHAR(64) PRIMARY KEY,
    display_name VARCHAR(100) NOT NULL,
    spotify_artist_id VARCHAR(100),
    social_links JSONB
);

CREATE TABLE bbq_embed_links (
    embed_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    creator_id VARCHAR(64) REFERENCES bbq_creators,
    media_type bbq_media_type_enum NOT NULL,
    target_resource_id VARCHAR(255) NOT NULL,
    embed_slug VARCHAR(100) UNIQUE NOT NULL,
    theme_color VARCHAR(20) DEFAULT '#1db954'
);
